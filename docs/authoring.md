# Authoring guide

The guide is split by task:

- [Getting started](getting-started.md): install, create a project, edit it
  while it plays, and build a game to share.
- [Story reference](story-reference.md): Story scripts, text, characters,
  sound, variables, scenes, importing drafts, layered portraits and motion.
- [UI reference](ui-reference.md): TSX screens, Player actions and data,
  settings, save management, input, custom effects.
- [Shipping reference](shipping.md): distributions, releases, saves across
  versions, patches and overlays, user data, play tests, importers, Android.
